# Discord-Bot: Nutzungsbedingungen & Datenschutzerklärung

Enthalten:
- `terms.html` – Nutzungsbedingungen
- `privacy.html` – Datenschutzerklärung

## Vor dem Veröffentlichen
1. Ersetze **alle Texte in eckigen Klammern** durch korrekte Angaben.
2. Prüfe die Datenschutzerklärung anhand dessen, was dein Bot tatsächlich speichert, und anhand deiner Hosting-/Datenbankanbieter.
3. Aktualisiere das Datum und entferne die hervorgehobenen Vorlage-Hinweise erst, wenn alles geprüft ist.
4. Diese Dateien sind Vorlagen und keine Rechtsberatung.

## GitHub Pages
GitHub Pages kann HTML-Dateien aus einem Repository veröffentlichen. Lege beide Dateien im Repository ab und aktiviere unter **Settings → Pages** das Veröffentlichen aus deinem Branch. Die Seiten sind dann typischerweise unter diesen Pfaden erreichbar:
- `https://DEINNAME.github.io/REPOSITORY/terms.html`
- `https://DEINNAME.github.io/REPOSITORY/privacy.html`

Offizielle Anleitung: https://docs.github.com/en/pages/quickstart
